# Pijat Panggilan Landing Page

Website statis sederhana (Landing Page) untuk jasa pijat panggilan, dibangun dengan HTML dan Tailwind CSS.

## Desain & Fitur
- Desain eksklusif dengan paduan warna Hijau Tua dan Emas.
- Struktur *Single Page* untuk konversi maksimal.
- Terintegrasi langsung dengan WhatsApp untuk pemesanan.
- Responsif (cocok untuk HP, Tablet, dan Desktop).

## Cara Menjalankan
Buka file `index.html` langsung di browser kesayangan Anda. Tidak perlu server khusus karena menggunakan Tailwind dari CDN.
